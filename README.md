# Palette

Universal creative control layer.

## Current foundation

`WaveExplorer_V2/` is the working Swift package that verifies the Tangent
Wave hardware layer before Palette adds Resolve or DCTL features. It includes
the TIPC transport, typed Wave events, OLED writes, control naming, a small
debug app, and tests.

See `WaveExplorer_V2/README.md` and `docs/CHATGPT_HANDOFF_2026-08-09.md` for
the current implementation and verified milestone.
